# Extractable components

## SiteHeader
- Category: layout
- Source: repeated root-page header markup
- Props: active route, CTA href, CTA label

## SiteFooter
- Category: layout
- Source: repeated root-page footer markup
- Props: featured guide href

## PrimaryButton
- Category: basic
- Source: styles.css button selector
- Props: href, label, variant

## ProductRecommendation
- Category: basic
- Source: affiliate guide pick selector
- Props: name, category, verdict, attributes, affiliate URL
